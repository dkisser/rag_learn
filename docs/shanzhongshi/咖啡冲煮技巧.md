# 咖啡冲煮完全教程：从器具到三种烘焙度的冲煮方案


## 一、冲煮前的准备：核心器具选择

手冲咖啡真正不可省略的核心器具只有四样：**磨豆机、滤杯、手冲壶、承接容器**。

### 1. 磨豆机——最值得投资的设备

磨豆机是手冲咖啡的“灵魂”，研磨均匀度直接决定风味的干净程度。**预算允许的情况下，磨豆机是最值得投资的设备**。

- **新手入门**（200-300元）：HERO Z3、巫师全能、泰摩栗子C3等手摇磨豆机，研磨浅烘豆时手感丝滑
- **一步到位**：1Zpresso K-Max、Comandante C40/C60，研磨均匀度和稳定性极佳
- **电动磨豆机**：Fika 6001T等带称重出粉功能的机型，残粉率可控制在0.2g以内
- **避坑**：几十元的刀片式粉碎器是手冲“头号杀手”，研磨颗粒极不均匀

### 2. 滤杯——决定萃取节奏

| 滤杯类型 | 流速 | 风味倾向 | 推荐烘焙度 | 代表型号 |
|---|---|---|---|---|
| V60锥形 | 快/中速 | 花香果酸突出、层次分明 | 浅烘 | Hario玻璃V60、泰摩冰瞳 |
| Kalita梯形 | 中慢速 | 口感醇厚、甜感平衡 | 中深烘 | Kalita 155陶瓷 |
| 蛋糕平底 | 慢速浸泡 | 容错率高、甜感饱满 | 全烘焙度 | 泰摩冰瞳B75 |

**新手建议**：V60教程最多、玩法丰富，是练基本功的首选。Kalita容错率更高，对注水手法不敏感，不容易过萃。

### 3. 手冲壶——控水的关键

选择**4-6mm口径的细嘴壶**，保证水流稳定。预算有限时，哈利欧云朵壶是性价比之选；需要温控功能可考虑轰炸机爸爸手冲壶。

### 4. 其他必备配件

- **电子秤**：需精确到0.1g，是科学冲煮的基础
- **滤纸**：必须与滤杯严格对应（V60用锥形#2，Kalita用扇形#50）
- **分享壶**：耐热透明以便观察液面


## 二、冲煮通用流程（适用于所有烘焙度）

无论什么烘焙度，冲煮的基本步骤相同，差异在于参数：

**Step 1 称豆与挑豆**：称取所需咖啡豆，剔除瑕疵豆（虫豆、霉豆、颜色明显不匀的豆子）。

**Step 2 研磨**：根据烘焙度调整研磨粗细（详见下文各烘焙度参数）。

**Step 3 预热器具**：用热水冲洗滤纸、滤杯和分享壶，去除纸味并预热器具。

**Step 4 布粉**：将研磨好的咖啡粉倒入滤杯，轻轻整平表面。

**Step 5 闷蒸**：用约2倍粉量的热水均匀打湿咖啡粉，静置20-30秒排出二氧化碳。

**Step 6 注水萃取**：按各烘焙度方案分段注水。

**Step 7 完成**：达到目标水量后移开滤杯，享用咖啡。


## 三、三种烘焙度的冲煮方案

### 🟢 浅烘豆（花果香、酸感明亮）

**核心思路**：提高萃取效率，把风味“榨”出来。浅烘豆密度高、难萃取，需要更高水温、更细研磨来充分释放花果香气。

| 参数 | 建议值 |
|---|---|
| 水温 | 91-94℃ |
| 研磨度 | 细砂糖颗粒，C40约18-32格 |
| 粉水比 | 1:15-1:16（如15g粉用225-240ml水） |
| 萃取时间 | 1分40秒-1分55秒 |
| 手法 | 30秒闷蒸后，大水流快冲，3-4次大水流注水 |

**手法详解**：
1. 闷蒸：用30g热水均匀打湿粉层，等待30秒
2. 第二段：绕圈注水至120g
3. 第三段：大水流中心定点注水至目标水量（约225g）
4. 总用时控制在2分钟内

> 💡 浅烘豆怕“没味道”，如果冲出来偏淡或酸味不足，可以提高水温或研磨更细。


### 🟡 中烘豆（平衡、坚果甜感）

**核心思路**：保留前中段风味，平衡酸甜苦。中烘豆参数介于浅烘和深烘之间，经典三段式最稳。

| 参数 | 建议值 |
|---|---|
| 水温 | 88-91℃ |
| 研磨度 | 砂糖颗粒，C40约36-40格 |
| 粉水比 | 1:15-1:16 |
| 萃取时间 | 2分-2分10秒 |
| 手法 | 30秒闷蒸后，中心硬币大小打圈注水 |

**手法详解**：
1. 闷蒸：用30-40g热水打湿粉层，等待30秒
2. 第二段：从中心开始绕圈注水，水流匀速稳定
3. 持续萃取至目标水量（1:15比例约225ml）
4. 总用时控制在2分10秒内

> 💡 中烘豆容错率最高，是新手练习的最佳选择。如果偏苦，降低水温；偏酸，提高水温。


### 🔴 深烘豆（巧克力、坚果、醇厚）

**核心思路**：降低萃取效率，避免过萃出苦杂味。深烘豆膨胀率高、脆度大、易萃取，需要更低水温、更粗研磨来防止过度萃取。

| 参数 | 建议值 |
|---|---|
| 水温 | 85-88℃ |
| 研磨度 | 粗海盐颗粒，C40约40-45格 |
| 粉水比 | 1:13-1:15 |
| 萃取时间 | 2分30秒-3分钟 |
| 手法 | 小水流，中心硬币大小打圈，缓慢萃取 |

**手法详解**：
1. 闷蒸：深烘豆吸水性强，可用40g水闷蒸，时间20-25秒（缩短时间降低萃取率）
2. 第二段：小水流从中心开始缓慢绕圈注水
3. 避免水流接触滤纸边缘
4. 持续萃取至目标水量

**日式慢滴法（进阶）** ：
- 水温80-82℃
- 粉水比1:8-1:10
- 不润湿滤纸也不闷蒸，直接中心点滴注水
- 萃取时间4-5分钟
- 适合追求极致醇厚、无酸口感的玩家

> 💡 深烘豆怕“太苦”，如果喝起来有明显焦苦味，降低水温或研磨更粗。


## 四、快速参考卡

| 烘焙度 | 水温 | 研磨度 | 粉水比 | 萃取时间 | 核心思路 |
|---|---|---|---|---|---|
| 浅烘 | 91-94℃ | 细（细砂糖） | 1:15-1:16 | 1:40-1:55 | 高温快冲，榨出花果香 |
| 中烘 | 88-91℃ | 中（砂糖） | 1:15-1:16 | 2:00-2:10 | 三段式，平衡酸甜苦 |
| 深烘 | 85-88℃ | 粗（粗海盐） | 1:13-1:15 | 2:30-3:00 | 低温慢冲，控苦提醇 |

> **记住一句话**：浅烘怕萃不足，中烘求平衡，深烘怕过萃。所有参数都可以根据个人口味微调——咖啡太酸就提高水温，太苦就降低水温。
