# 磨粉服务

**关于磨粉 / Grinding Instructions**
- 请拍默认 **"不磨粉"** 选项，并备注即可。

---

## 注意事项

1. **意式研磨无法适配市面上所有机型**，如遇萃取问题，请咨询客服为您提供调整萃取方案。  
2. 磨粉后豆子的赏味期会受到影响，**强烈建议现磨现喝**，如必须代磨，请尽快饮用哦。  
3. 咖啡豆磨粉属于定制服务，**研磨后不接受退换**。

---
