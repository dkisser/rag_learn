# 售后

## 破损包退

签收72小时内（食品24小时），发现商品破损、变形、漏液（粉）等情形并提供有效凭证，卖家会在24小时内响应并退款，未履行服务每个订单将赔付实际退款金额10%

## 大促价保

订单付款后，若在价保期（在订单详情展示）内降价，可通过"手机淘宝首页搜索-价保中心"申请补差，部分特定场景除外

## 退货宝

退货运费险保障：选择上门取件，自动减免首重运费；若选择自寄，参照首重标准补偿，具体以"订单详情-退货宝"为准

## 极速退款

满足相应条件时，信誉良好的用户在退货寄出后，享受极速退款到账。

## 7天无理由退货

满足相应条件（密封包装拆封后不支持）时，消费者可申请 "7天无理由退货"

## 88VIP退货包运费

平台指定上门取件可用，每单最高可抵扣25元运费（以退换货时实际剩余可用的权益额度为准），使用退货宝（或运费险）或其他运费优惠/权益后剩余运费可享抵扣
