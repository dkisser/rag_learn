# 烘焙度参考（AGTON Index）

| 烘焙度 | AGTON Index 范围 | 风味描述 |
|--------|----------------|----------|
| 浅度烘焙 | 95–86 | 明快的花果香，产地风味显著，偏向清澈的酸甜感，微青草香 |
| 中浅烘焙 | 85–76 | 清爽的果汁、糖果，愉悦的酸甜，多汁的口感 |
| 中度烘焙 | 75–66 | 甜美的成熟水果，坚果风味初显，甜感柔和舒适 |
| 中深烘焙 | 65–56 | 饱满的奶油可可，果实的余韵悠长，焦糖风味开始体现 |
| 深度烘焙 | 55–46 | 顺滑浓郁的黑巧，扎实的口感，咖啡本味浓郁清晰 |
